# \# Vehicle Rental Web Application

# 

# A responsive web application developed with HTML, CSS, and vanilla JavaScript.

# 

# The project focuses on building a responsive marketplace-style interface with vehicle listings and other categorized advertisements, while following modern HTML5 and CSS development practices.

# 

# \## Features

# 

# \- Fully responsive layout for desktop, tablet, and mobile devices

# \- Vehicle listing and advertisement pages

# \- Multi-page website structure

# \- Responsive navigation and page layouts

# \- Client-side form validation

# \- Password confirmation validation

# \- Full-name validation

# \- Age validation

# \- Reusable CSS styles

# \- Semantic HTML5 structure

# 

# \## Technologies

# 

# \- HTML5

# \- CSS3

# \- JavaScript

# 

# \## Front-End Development

# 

# The user interface was implemented using HTML, CSS, and vanilla JavaScript.

# 

# The project follows web development practices documented by MDN Web Docs and W3C, with an emphasis on semantic HTML, reusable CSS rules, responsive layouts, and accessibility.

# 

# JavaScript is used for client-side interaction and form validation through the browser's Constraint Validation API.

# 

# \## Responsive Design

# 

# The website was designed to adapt to different screen sizes, including:

# 

# \- Desktop

# \- Tablet

# \- Mobile

# 

# CSS Grid, Flexbox, media queries, and reusable styles are used throughout the application.

# 

# \## Purpose

# 

# The project demonstrates practical experience with responsive front-end development, semantic HTML5, CSS layouts, and client-side JavaScript.
