# Vehicle Rental Web Application

A responsive full-stack web application for browsing and managing vehicle rental listings.

The project was developed using HTML, CSS, and JavaScript for the front end, with Node.js providing the backend functionality and REST-based communication between the client and server.

## Features

- Responsive interface for desktop, tablet, and mobile devices
- Vehicle listing and rental-oriented pages
- Client-side form validation using the JavaScript Constraint Validation API
- Node.js backend
- REST API communication
- Reusable CSS styling and responsive layouts
- Semantic HTML5 structure

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- REST APIs

## Front-End Development

The user interface was implemented with HTML, CSS, and JavaScript, following modern web development practices documented by MDN Web Docs and W3C.

The layout is fully responsive and adapts to desktop, tablet, and mobile screen sizes.

JavaScript is used for client-side interaction and form validation, including password matching, full-name validation, and age validation.

## Backend

The backend is implemented using Node.js and communicates with the client through REST endpoints.

## Purpose

The project demonstrates practical experience with responsive web development, client-side validation, server-side JavaScript, and REST-based client-server communication.
